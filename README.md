# Visomaster-Lite-Extensions-Repo
The extensions repository for VisoMaster Lite


### How to use:

Simply browse the extensions folder here, inside there will be folders with each extension.
Expect a readme and the extension itself inside each. Just download the .py file of the extension 
and place it in your "...VisoMaster-Lite\extensions" folder.


### How to send your own:

You can send a PR OR simply upload a zip file with it in the Issues section by selecting the 
"Extension submission" in the menu. I will check it and add it if all is fine. 
Don't get mad if it takes some time 😁.

The expected format is "...\extension_name\extension.py" and include a readme in it with all the info.

```text
extension_name/
├── README.md
└── extension.py
```
