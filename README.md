# Visomaster-Lite-Extensions-Repo
The extensions repository for VisoMaster Lite


### How to use:

Simply browse the extensions folder here, inside there will be folders with each extension.
Expect a readme and the extension itself inside each. Just download the .py file of the extension 
and place it in your "...VisoMaster-Lite\extensions" folder.


### How to send your own:

You can send a PR OR simply upload a zip file with it in the Issues section with "[NEW EXTENSION]" in the
title of the issue. I will check it and add it if all is fine. Don't get mad if it takes some time 😁.
