# Job Manager

An extension for VisoMaster Lite that lets you configure jobs to run them when you want.
This is the VisoMaster Fusion's job manager functionality ported as an extension so users can now
opt-in or out to use it. 


### Install

Just place the job_manager.py file inside the "extensions"
dir inside the app and VisoMaster Lite will automatically pick it up.
